# Once Human クラフト管理アプリ(GAS版)

スプレッドシートをDBにした、完全無料のクラフト素材管理Webアプリです。

## できること
- 作りたいアイテムと個数から、中間素材も含めて自動展開し、**不足素材**を算出
- チーム共有在庫の管理、納品ログ、貢献ランキング
- レシピはアプリ上でCSV形式のまま編集
- 不足リストのコピー / Discord Webhook通知
- 合言葉(任意)による書き込み制限

## セットアップ(コピペだけで完了)
1. Googleスプレッドシートを新規作成 → **拡張機能 → Apps Script**
2. `Code.gs` の内容を貼り付ける
3. 左の「+」→ **HTML** で `index` という名前のファイルを作り、`index.html` の内容を貼り付ける
4. (任意)プロジェクトの設定 →「appsscript.json をエディタで表示」をオンにして、`appsscript.json` を貼り付ける
5. 関数 `setup` を選んで **実行**(初回のみ。権限の承認が必要)
   → 「レシピ」「在庫」「納品ログ」「目標」シートが作られます(サンプルデータ入り)
6. **デプロイ → 新しいデプロイ → ウェブアプリ**
   - 次のユーザーとして実行: **自分**
   - アクセスできるユーザー: **全員**(Googleログイン必須。URLを知る人のみ利用)
7. 発行されたURLをDiscordで共有

## 任意設定(プロジェクトの設定 → スクリプト プロパティ)
| キー | 内容 |
|---|---|
| `PASSPHRASE` | 設定すると、書き込みに合言葉が必要になります(アプリの「設定」タブで入力) |
| `DISCORD_WEBHOOK` | DiscordのWebhook URL。設定すると不足リストを通知できます |

## レシピの書き方
```
# アイテム,素材,必要数,1回の生産数(省略時1)
武器A,部品B,2,1
武器A,鉄,10,1
部品B,鉄,3,2
```
素材が別アイテムのレシピに載っていれば自動で再帰展開されます。中間素材の在庫があればそれを先に消費します。
同梱のレシピはサンプルです。ゲーム内の実データに置き換えてください。

## 運用メモ
- コードを更新したら「デプロイを管理 → 編集 → 新バージョン」で再デプロイが必要です。
- 同時書き込みは `LockService` で排他制御しています。
- 書き込みAPIは合言葉で保護されますが、閲覧は誰でも可能です。URLの扱いにご注意ください。
- 無料枠: UrlFetch 2万回/日、実行時間 90分/日(無料Googleアカウント)。数十人規模なら十分です。
